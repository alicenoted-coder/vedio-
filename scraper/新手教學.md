# 新手教學：從零開始把爬蟲跑起來

這份是給「**完全沒用過終端機**」的人看的。跟著一步一步做即可。
全程大概 15 分鐘（第一次裝東西比較久）。

> 重要觀念：這些指令要在**你自己的電腦**上跑，不能貼進跟 AI 聊天的對話框。
> 因為要用到你電腦上的瀏覽器去登入、抓資料。

---

## 第 0 步：先搞懂「終端機」是什麼

終端機就是一個可以打指令的黑色（或白色）視窗。

- **Windows**：按開始 → 搜尋 **PowerShell** → 點開。
- **Mac**：按 `Cmd + 空白鍵` → 輸入 **終端機** 或 **Terminal** → 按 Enter。

之後所有「指令」都是貼進這個視窗、按 Enter 執行。

---

## 第 1 步：安裝 Node.js（只需一次）

Node.js 是跑這支程式的引擎。

1. 開瀏覽器到 <https://nodejs.org>
2. 下載左邊那顆 **LTS（長期支援版）** 按鈕。
3. 打開下載的檔案，一路「下一步 / 繼續」裝完。

裝好後，回到終端機，貼這行確認（看到版本號就成功）：

```bash
node -v
```

看到類似 `v20.11.0` 就 OK。如果說「找不到指令」，把終端機關掉重開一次。

---

## 第 2 步：下載這個專案

### 方法 A：用 git（如果你電腦有 git）

```bash
git clone https://github.com/alicenoted-coder/claude.git
cd claude
git checkout claude/social-media-data-extraction-mebo1b
```

### 方法 B：直接下載 ZIP（沒有 git 也行）

1. 開 <https://github.com/alicenoted-coder/claude/tree/claude/social-media-data-extraction-mebo1b>
2. 按綠色 **Code** 按鈕 → **Download ZIP**。
3. 解壓縮，記住資料夾位置（例如桌面）。
4. 在終端機切換到那個資料夾。教學：打 `cd `（cd 後面有一個空格），然後把資料夾**拖進終端機視窗**，按 Enter。

---

## 第 3 步：安裝套件 + 瀏覽器（只需一次）

### 懶人法：點兩下自動裝 ⭐ 推薦

專案資料夾裡有準備好的安裝檔，打開資料夾直接點兩下：

- **Windows**：點 `安裝-Windows.bat`
- **Mac**：點 `安裝-Mac.command`
  （如果 Mac 跳出「無法打開，因為來自未識別的開發者」：對檔案**按右鍵 → 打開**，再按一次「打開」即可。）

看到「全部裝好了！」就完成，直接跳到第 4 步。
如果安裝檔跑失敗，再用下面的手動法。

### 手動法

確認終端機現在在專案資料夾裡（前面方法做完就是了），依序貼：

```bash
npm install
```

等它跑完（會出現一堆字，正常）。接著：

```bash
npx playwright install chromium
```

這會下載一個專用的瀏覽器，約 150MB，等它跑完。

---

## 第 4 步：登入（抓 Instagram / Facebook 才需要）

蝦皮通常**不用**登入，可以跳過這步。
要抓 IG / FB 的話：

```bash
npm run scrape -- login instagram
```

- 會自動跳出一個瀏覽器視窗。
- 在裡面**用你的帳號登入** Instagram（該過驗證就過）。
- 登入完成後，**回到終端機按 Enter**。
- 看到「已儲存登入狀態」就成功，視窗會自己關掉。

（要抓 FB 就把上面的 `instagram` 換成 `facebook`。）

---

## 第 5 步：開始抓資料

### 蝦皮賣場

把 `someshop` 換成真實賣場的代號。代號就是賣場網址 `shopee.tw/` 後面那串，
例如 `shopee.tw/apple.tw` 的代號就是 `apple.tw`。

```bash
npm run scrape -- shopee --shop someshop --limit 100
```

`--limit 100` 是最多抓 100 個商品，可自己改數字。

### Instagram

把 `natgeo` 換成你要看的帳號（不用加 @）：

```bash
npm run scrape -- instagram --user natgeo --limit 30
```

### Threads / Facebook

```bash
npm run scrape -- threads  --user natgeo --limit 30
npm run scrape -- facebook --page somepage
```

---

## 第 6 步：找到結果

跑完終端機會印出像這樣：

```
完成：profile 1、product 87、post 0 筆 → data/shopee-someshop.csv
```

那個 `data/` 資料夾就在你的專案資料夾裡。
打開 `data/shopee-someshop.csv`，用 **Excel** 或 **Google 試算表** 開即可（已處理繁中編碼，不會亂碼）。

## 常見問題

| 狀況 | 解法 |
|------|------|
| `command not found: node` / `npm` | Node.js 沒裝好，或終端機沒重開。回第 1 步。 |
| `command not found: git` | 用第 2 步的「方法 B：下載 ZIP」。 |
| 蝦皮報錯 `拿不到賣場資料` | 代號打錯，或被蝦皮暫時擋。等幾分鐘再試，或加 `--headful` 看瀏覽器發生什麼事。 |
| IG/FB 抓到 0 筆 | 八成是沒登入。先做第 4 步 `login`。 |
| 想看瀏覽器在做什麼 | 任何指令後面加 `--headful`，會顯示視窗。 |
